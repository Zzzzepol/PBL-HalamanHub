LOCAL MONGODB SETUP GUIDE
macOS and Windows

Purpose
-------
This guide installs MongoDB Community Edition on your laptop and checks that
it runs locally. The laptop's backend will connect to MongoDB. The ESP32 and
admin page should send requests to the backend, not connect directly to MongoDB.

IMPORTANT FOR HALAMANHUB
-----------------------
The current backend uses one MONGODB_URI for all its models. Do not replace
that value with a local address yet: doing so would point shop data to the
laptop too. First install and verify local MongoDB. The backend then needs to
be updated to use two connections:

  Local MongoDB: sensor readings and watering settings
  Cloud MongoDB: online shop products, customers, and orders

The future local connection address will be:

  mongodb://127.0.0.1:27017/halamanhub_iot

This address is for the backend running on the same laptop.


MACOS
-----
Requirements
  - MongoDB 8.0 supports macOS 14 or later on Intel and Apple Silicon.
  - Homebrew is required for these commands.
  - If needed, install Apple's command-line tools with:

      xcode-select --install

  - Install Homebrew using its official guide:
      https://brew.sh/

Install MongoDB
  1. Open Terminal.
  2. Run these commands:

      brew tap mongodb/brew
      brew trust mongodb/brew
      brew update
      brew install mongodb-community@8.0
      brew services start mongodb-community@8.0

Connect and verify
  1. In Terminal, run:

      mongosh "mongodb://127.0.0.1:27017"

  2. At the mongosh prompt, run:

      db.runCommand({ ping: 1 })

  3. A successful response includes:

      ok: 1

Stop MongoDB
  To stop the background service later, run this in Terminal:

      brew services stop mongodb-community@8.0

Official installation guide:
  https://www.mongodb.com/docs/v8.0/tutorial/install-mongodb-on-os-x/


WINDOWS
-------
Requirements
  - MongoDB 8.0 supports 64-bit Windows 11 and Windows Server 2022.
  - The MongoDB server installer does not include mongosh; install the shell
    separately, as described below.

Install MongoDB Server
  1. Open the official Community download page:
       https://www.mongodb.com/try/download/community
  2. Select the Windows platform and MSI package, then download it.
  3. Run the MSI installer.
  4. Choose Complete.
  5. Select "Install MongoD as a Service" and keep the default service name
     "MongoDB". Compass is optional.
  6. Finish the installer. The MongoDB service should start automatically.

Install mongosh
  1. Open the official MongoDB Shell download page:
       https://www.mongodb.com/try/download/shell
  2. Download and install the Windows version. Add mongosh to PATH if the
     installer offers that option.

Connect and verify
  1. Open Command Prompt or PowerShell.
  2. Run:

       mongosh "mongodb://127.0.0.1:27017"

  3. At the mongosh prompt, run:

       db.runCommand({ ping: 1 })

  4. A successful response includes:

       ok: 1

Start or stop MongoDB
  Open the Windows Services app, find "MongoDB", and choose Start or Stop.

Official installation guide:
  https://www.mongodb.com/docs/v8.0/tutorial/install-mongodb-on-windows/


AFTER THE CHECK
--------------
Once the ping succeeds, local MongoDB is running. Do not change the existing
MONGODB_URI in the HalamanHub server yet. The next project step is to refactor
the backend so sensor and watering models use the local connection while shop
models continue using the cloud connection. Mongoose supports multiple
connections:

  https://mongoosejs.com/docs/connections.html

Keep database connection strings and passwords in the server's environment
file. Do not put them in frontend code or share them publicly.
